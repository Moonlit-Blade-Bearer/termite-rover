## 协议（与原训练完全一致）

- 只用 `split.json` 固化的会话级划分，不重新生成；
- 特征归一化 `feat_mean/feat_std`、标签 `y_mean/y_std` **只在 train 上拟合**；
- 选点用 **val AUC**（原回归用 val MAE），测试集只在最后评估一次；
- 训练/验证/测试：122,401 / 26,545 / 25,846 个窗口，正样本率 47.8% / 49.5% / 63.6%。

## 模型

`model.py` 新增 `MultiTaskCNN`（保留原 `DepthCNN` 不动）：

```
共享骨干：Conv1d(20→32→64→128, k=5, BN, ReLU, MaxPool2) → 128×10
├─ depth_head：Flatten → Linear(1280→64) → ReLU → Dropout → Linear(64→1)   板厚回归
└─ cls_head  ：Flatten → Linear(1280→64) → ReLU → Dropout → Linear(64→1)   白蚁 logit
```

- 参数：218,946
- 损失：`MSE(depth_norm) + 1.0 × BCEWithLogits(termite)`

## 风险与限制

1. **没有活体实测**：训练/评估全部来自现有数据集；真实木板 + 活白蚁的表现需补测。
2. **概率未校准**：样本可分时 BCE 输出会饱和（0.000 / 1.000），若下游要按概率决策，需要温度缩放/Platt 校准。
3. **测试集分布偏移**：测试集正样本率（63.6%）明显高于训练集（47.8%），准确率会显得偏高；**AUC/敏感度/特异度** 更可信。
4. **多任务轻微拖累回归**：深度 MAE 5.497 vs 5.3 mm，若深度指标更关键，可提高回归损失权重或改回两阶段（先分类、再回归）。
