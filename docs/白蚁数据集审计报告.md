```

 └─ 椴木/胡桃木/榉木/樱桃木 ◄── 木种（4）

                 ├─ radar_config_snapshot.txt  mmwDemo 雷达配置快照（由 people_counting demo 改制）
```

## 4. 发现的问题（按影响排序）

1. **任务定义错位（最重要）**：`session_metadata.json` 中 `depth_mm` 全部为 -1、`cavity_id/colony_id/room` 全为空、`wood_type/board_id/operator` 607 会话为 unknown。**"深度"从未被真值标注**——现有 DepthCNN 训的标签实为**板厚**（npz y ∈ {0,5,…,50}），代码注释里的"板厚/深度回归"实际=板厚回归。若目标本来就是"测板厚"，应改名《ThicknessNet》；若目标真是"白蚁空洞深度"，须补人工标注 depth_mm。
2. **厚度 ≥45mm 系统性坍缩**：1100 测试窗复现结果 MAE 5.275mm / RMSE 7.739 / R²=0.738，但**45mm 偏差 -7.9mm、50mm 偏差 -9.4mm**（预测集中在 37–41mm）。与 60GHz 穿干松木 ≈8.5 dB/cm 的物理衰减完全吻合——**数据没有毛病，是物理极限**，模型在 40mm 之外特征饱和。
3. **白蚁信号间歇性强弱不一（配对能量检验）**：同(木种,地点,湿度,厚度)配对下 top5 通道能量比：

| 厚度 | 中位对比度 | 备注 |
| --- | --- | --- |
| 5mm(椴) | **+12.0 dB** | 两对一致 (+9.7/+14.2) |
| 10mm(椴) | +2.2 dB | 一对 +5.2、一对 -0.8 |
| 15mm(椴) | +3.6 dB | 正 |
| 20mm(椴) | +4.2 dB | 正 |
| 25mm(椴) | **+19.4 dB** | 两对高度一致 (+18.8/+19.9) |
| 30mm(椴) | -1.3 dB | 一正一负 |
| 35mm(椴) | +1.3 dB | |
| 40mm(椴) | +4.3 dB | 正 |
| 45mm(椴) | -11.8 dB | 一对 +5.0、一对 **-28.6**（无白蚁会话噪声 top5=2682，常态仅 40–110） |
| 50mm(椴) | +26.0 dB | 单对（另一会话文件截断 StopIteration，见问题 4） |
| 30mm(核) | +5.5 dB | 第一轮检验 |
| 10mm(榉) | +0.4 dB | 第一轮检验 |
| 45mm(榉) | +0.8 dB | 第一轮检验 |

   解读：**信号真实存在**（5/25/50mm 的强案例无法用噪声解释），但**不随厚度单调、且会话间差异大**——原因是白蚁活动有间歇性（40s 窗口可能恰好赶上不动时刻）、空腔/白蚁团与雷达波束的对位不固定、以及个别"无白蚁"会话被外部振动/干扰污染。结论：**原始数据可用，但按"能量均值"做判别不可避免地抖动；分类任务必须按会话/时间块聚合特征**，而不是指望每个窗口独立可分。
4. **个别文件截断**：50mm 椴木 0湿度某会话 `..._50mm_location-1_time-20260831T113626_...part_0000.csv` 三次读块均 StopIteration（文件不完整）→ 逐会话校验帧数完整性，损坏会话应剔除后再训练。
5. **RTC 失效会话 140/747**：文件名时间戳为 `20000101T000000`（主板时钟未同步），不破坏内容，但破坏"跨会话按时间排序/审计"和与人工观察录像对齐的能力。会话仍可依赖 metadata 里的相对信息，但建议补记真实采集时间。
6. **雷达配置快照自 people_counting demo 改制**：profileCfg/frameCfg 参数建议按 TI CLI 手册逐字段复核（尤其带宽/斜率），确认 20 个距离 bin 的实际量程与分辨率量级（粗算 4GHz 带宽 → 3.75cm 分辨率，即 5mm 档的"厚度"不可能来自距离门选通，而是来自衰减/微动强度特征——这也解释了模型退化的位置）。
7. **划分防泄漏待确认**：checkpoint `val_metrics.n=26545`，而 747 会话 × 4 窗/会话 ≈ 2,988——实际用了滑窗采样（window_idx 最大 174,096 亦佐证）。**必须确认划分键是"会话"而不是"窗口"**：同一会话的相邻 256 帧窗口高度相关，若同会话窗口跨 train/test，指标会虚高。
8. 细节：`无白蚁\榉木\地点3` 缺 60湿度档等零星缺格；两套目录命名体例（时间戳式/mm 式）并存，建议统一。

## 6. 总体结论（三层可信度）

1. **采集工程可信度：高**。帧率、丢包、双份存档、元数据纪律都是专业水平。
2. **标注一致性可信度：高**。文件名↔元数据 0 冲突；网格设计系统。缺口是"深度真值从未标注"+ 140 会话时钟失效 + 个别文件损坏。
3. **科学有效性：条件成立**。板厚回归模型成立（受 60GHz 物理上限约束，≥45mm 失效是有物理依据的，不叫作弊）；**白蚁存在性判别**目前只是"间歇可分"——要按会话聚合+剔除异常会话+补标注后才算立得住。
