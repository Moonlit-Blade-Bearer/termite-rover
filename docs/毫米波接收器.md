# 毫米波接收器（T9.1 落盘）

## 硬件与端口

| 项 | 值 |
| --- | --- |
| 雷达 | IWR6843AOPEVM（mmWave Demo，SDK 03.05.00.04，xWR68xx_AOP） |
| USB 桥 | CP2105 双串口（`10c4:ea70`） |
| CFG 口 | `/dev/radar_cfg`（接口 0，115200，CLI） |
| 数据口 | `/dev/radar_data`（接口 1，921600，二进制流） |

接口号会随插拔漂移，且与 RPLIDAR 同为 `10c4` 厂商，因此用 `scripts/99-radar.rules` 按 `idProduct + ID_USB_INTERFACE_NUM` 固定符号链接。

## 配置

数据集每个会话都带 `radar_config_snapshot.txt`，已提取为 `scripts/radar_dataset.cfg`（与原采集完全一致）：

```text
configDataPort 921600 1
sensorStop
flushCfg
...
profileCfg 0 60 15 2 36 0 0 110 1 64 2000 0 0 40
frameCfg 0 2 16 0 10 1 0      # 100 Hz 帧率
...
sensorStart
```

> `configDataPort 921600 1` 会把数据口波特率切到 921600，主机要在发完 cfg 之后再打开数据口。

## 帧格式（实测，与数据集 raw_uart 完全同构）

```
384 字节 / 帧，100 帧/秒
┌ magic (8 B)：01 01 04 03 06 05 08 07
├ 天线 1：ts (4 B, LE) + 20 bin × (Q, I) int16      ← 记录 96 B
├ 天线 2：同结构（偏移 104）
├ 天线 3：同结构（偏移 200）
└ 天线 4：同结构（偏移 296）
```

- **wire 顺序是 Q 在前、I 在后**；数据集 CSV 是 I 在前、Q 在后，接收器已转换。
- `ts` 是设备侧时间戳（每帧 +10，即 100 Hz 计数）。
- 帧率实测：99.5–99.9 fps，0 坏块。

## 使用方法

```bash
# 容器内（/dev 已挂载）
python3 scripts/radar_receiver.py --duration 30 \
    --out-csv radar.csv --out-raw radar.bin
```

参数默认值：`--cfg /root/ros2_ws/radar_dataset.cfg`、`--cfg-port /dev/radar_cfg`、`--data-port /dev/radar_data`。

输出 CSV 列与数据集一致（167 列）：

```
frame_id, host_time_ns, host_time_iso_utc, device_ts_a1..a4,
a1_b00_i, a1_b00_q, ..., a4_b19_i, a4_b19_q
```

同时生成 `*.summary.json`（帧数、实际帧率、坏块数）。

## T9.5 检测节点 `/termite/detection`（2026-11-26 打通）

节点 `termite_bringup/termite_detector`：

```
/dev/radar_cfg 配置雷达 → /dev/radar_data (921600)
    → radar_iq 解析/组帧 → 256 帧滚动窗口
    → 每 128 帧跑一次 CNN → std_msgs/String(JSON)
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `cfg_port` / `data_port` | `/dev/radar_cfg` / `/dev/radar_data` | 由 udev 固定 |
| `cfg_file` | `/root/ros2_ws/radar_dataset.cfg` | 数据集同款配置 |
| `ckpt` | `/root/ros2_ws/ml/best_full.pth` | 板厚回归模型 |
| `stride` | 128 | 每 1.28s 推理一次 |

实测：

```json
{"depth_mm": 16.31, "valid": true, "frames": 4113, "window": 256, "infer_ms": 150.0}
```

- `/termite/detection` ≈ 0.73 Hz（stride 128 @ ~98fps）
- 推理 150ms/次（冷启动约 400ms）
- 节点随 `mapping.launch.py` 自启，雷达不在时自动重试
- 资源：整机 CPU 19.7%（EKF 占大头）、可用内存 2.2GB

**容器内 torch**：装在挂载卷 `/root/ros2_ws/vendor/torch_pkgs`，CUDA 库借用宿主（compose 只读挂载 `cuda-10.2` 与 7 个 cuDNN `.so.8.2.1`，容器自带的 cuDNN 是 0 字节占位）。`entrypoint.sh` 负责设置 `PYTHONPATH`/`LD_LIBRARY_PATH`；缺失依赖用 `scripts/fix_container_libs.sh` 自动从宿主补齐。
