# K230 视觉链路（T5.1 / T5.2）

## 硬件与固件

| 项 | 值 |
| --- | --- |
| 板子 | CanMV K230（`k230_canmv_wondermk`，幻尔定制镜像） |
| 固件 | CanMV v1.5-legacy（MicroPython 3.4.0，2026-03-27 构建） |
| 摄像头 | GC2093（CSI2，1920×1080@30） |
| USB | VID:PID `1209:abd1`，暴露 CDC 串口 + UVC 摄像头 |
| 串口 | 枚举序号会变（ttyACM1/2/…），用 `scripts/99-k230.rules` 固定为 `/dev/k230` |

## 关键结论（都踩过坑）

1. **不要改名/删除 `/sdcard/main.py`**：这个幻尔镜像靠 `main.py → hw.start.main()` 初始化框架，删了之后 USB 还在枚举但 MicroPython REPL 完全无响应。
2. **无屏运行不能用 PipeLine**：`PipeLine.create()` 强制 `Display.init()`，面板型号不对会报 `init panel failed`。正确做法是直接用 `Sensor` + `Display.VIRT`：
   ```python
   sensor = Sensor(fps=30); sensor.reset()
   sensor.set_framesize(w=640, h=360, chn=CAM_CHN_ID_0)
   sensor.set_pixformat(Sensor.YUV420SP, chn=CAM_CHN_ID_0)
   info = sensor.bind_info(x=0, y=0, chn=CAM_CHN_ID_0)
   Display.bind_layer(**info, layer=Display.LAYER_VIDEO1)
   sensor.set_framesize(w=640, h=360, chn=CAM_CHN_ID_2)
   sensor.set_pixformat(Sensor.RGBP888, chn=CAM_CHN_ID_2)
   Display.init(Display.VIRT, width=640, height=360, fps=30, to_ide=False)
   sensor.run()
   ```
   chn0 必须绑定到 VO，否则 `snapshot(chn=2)` 会永久阻塞。
3. **YOLO 输入必须是 numpy**：`yolo.run(sensor.snapshot().to_numpy_ref())`，直接传 Image 会卡死。
4. **检测结果格式**：`res = [boxes, class_ids, scores]`，不是按类别分组。框是 `[x, y, w, h]`。
5. **vision_msgs 版本差异**：Humble 这版 `BoundingBox2D.center` 是 `Pose2D{position.x, position.y, theta}`，不是 `x/y`。
6. **REPL 抢占**：幻尔 demo 开机自启，需要发 Ctrl-C（可多次）才能拿到 `>>>`；打断时 USB 可能短暂重枚举。
7. `machine.WDT` 存在，脚本卡死时可用来定时复位。

## 性能实测

| 模型 | 输入 | 结果 |
| --- | --- | --- |
| fruit_det_yolov5n | 320×320 | 10 帧约 1s，无检出（画面无水果） |
| **yolov8n_320（COCO 80 类）** | 320×320 | **19.3 FPS**（30 帧 1557ms），person 连续检出 |

## 帧协议（T5.2）

USB CDC 上的 ASCII 行协议：

```
$D,<seq>,<json>,<crc16>\n
json = {"w":640,"h":360,"fps":19.1,"d":[["person",x,y,w,h,score], ...]}
crc16 = CRC-16/CCITT-FALSE(json)，4 位十六进制
```

- K230 每 2 帧发一次（约 9.4 Hz）；
- 解析时必须**从右往左切 CRC**（JSON 内部含逗号），再从左侧切 `$D` 和 `seq`；
- 未检出时 `d` 为空数组，仍按心跳发送。

## 节点

| 端 | 文件 | 说明 |
| --- | --- | --- |
| K230 | `scripts/k230_detector.py` | 无屏 YOLOv8n 检测 + 帧发送 |
| Jetson | `ros2_ws/src/termite_bringup/termite_bringup/vision_receiver.py` | 读 `/dev/k230`，校验 CRC，发布 `/detections` |
| 启动 | `ros2 launch termite_bringup vision.launch.py` | `respawn=True`，断线自动重连 |

发布消息：`vision_msgs/msg/Detection2DArray`，`frame_id=k230_camera`，bbox 归一化到 0..1。

## 启动方式（当前）

1. 用 `scripts/k230_repl.py` 抢到 REPL；
2. `--script scripts/k230_detector.py` 启动检测器（会打印 `$READY`）；
3. Jetson 侧 `ros2 launch termite_bringup vision.launch.py`。

> 尚未做 K230 开机自启（改动 `main.py` 有风险，暂缓）。当前是手动启动，板子复位后需要重新执行第 1–2 步。
