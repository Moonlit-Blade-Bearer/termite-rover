# 时间同步（T10.1）

**目标**：整车所有计算单元（Jetson / Pi5 / K230 / PC）共用一个可信时间基准，保证 rosbag、毫米波数据、视觉帧、日志可以互相对齐。

## 一、问题背景

- **Jetson Nano 没有 RTC 电池**：断电后开机时钟回到 2000-01-01，靠 NTP 校正需要几十秒。
- 容器是开机立刻启动的，如果不加保护，这段时间录的 bag / TF / 传感器时间戳全部是错的（偏差可达 26 年）。
- 之前 `who -b` 记录的上次启动时间是 `2000-01-01 09:00`，就是这个原因。

## 二、Jetson 侧（已完成 2026-11-26）

### 1. 用 chrony 替换 systemd-timesyncd

```bash
sudo apt-get install -y chrony
sudo systemctl disable --now systemd-timesyncd
```

### 2. `/etc/chrony/chrony.conf` 关键配置

```conf
# 国内低延迟 NTP
server ntp.aliyun.com iburst prefer
server time1.cloud.tencent.com iburst

# 给局域网授时（Pi5 / K230 / PC）
allow 192.168.0.0/24

# 关键：Ubuntu 默认 maxupdateskew 100 太严
maxupdateskew 1000.0
```

**两个坑（都踩过）**：

| 坑 | 现象 | 处理 |
| --- | --- | --- |
| `maxupdateskew 100.0` 太严 | 刚启动时样本少、频差估计上千 ppm，chrony 判定源不可信，退回本地时钟（`Stratum 10`，`Reference ID 7F7F0101`） | 放宽到 1000 |
| `local stratum 10` | 加上后 chrony 一直用本地时钟，不跟上游同步 | **不要加**（实测去掉后立刻同步到 `Stratum 3`） |

### 3. 验证

```bash
chronyc tracking        # 期望 Stratum 3，Reference ID 是公网 NTP
chronyc sources         # 期望有一行 ^*
ss -lun | grep :123     # 期望 0.0.0.0:123 在监听
```

实测结果：`Reference ID: 203.107.6.88`（阿里云），`Stratum 3`，系统偏差 15µs。

### 4. 开机时间守卫（关键）

`docker/entrypoint.sh` 在启动 ROS 之前等待年份正常：

```bash
for _ in $(seq 1 60); do
  year=$(date +%Y)
  [ "$year" -ge 2025 ] && break
  sleep 1
done
```

- 正常情况几秒内通过（RTC 或快速 NTP 校正）；
- 完全断网时最多等 60 秒，然后带警告继续启动（不会卡死）。

## 三、其他设备指向 Jetson

Jetson 地址：`192.168.0.108`（`allow 192.168.0.0/24` 已放行整个网段）。

### Linux（Pi5 / K230 / Ubuntu PC）

```bash
sudo apt-get install -y chrony
# /etc/chrony/chrony.conf 里加：
server 192.168.0.108 iburst
# 然后
sudo systemctl disable --now systemd-timesyncd
sudo systemctl restart chrony
chronyc tracking
```

### Windows（PC）

管理员 PowerShell：

```powershell
w32tm /config /manualpeerlist:"192.168.0.108" /syncfromflags:manual /reliable:no /update
Restart-Service w32time
w32tm /resync
w32tm /stripchart /computer:192.168.0.108 /samples:3 /dataonly
```

### 验证本机授时是否正常（从任意机器）

```powershell
w32tm /stripchart /computer:192.168.0.108 /samples:3 /dataonly
```

## 四、已知问题

| 问题 | 状态 |
| --- | --- |
| **PC 时钟比 Jetson 慢 12.27 秒**（2026-11-26 实测） | 待处理：PC 未对时。按上面 Windows 步骤配置即可 |
| Pi5 / K230 尚未接入 | 等机械臂/视觉节点上线时按第三节配置 |
| 车队断网时无上游 | 时间会自由漂移（晶振 ~20ppm，一天约 1.7 秒）；需要高精度时再考虑 GNSS 授时或加 RTC 模块 |
